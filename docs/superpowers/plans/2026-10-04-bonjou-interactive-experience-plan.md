   SHA-256 verification, bounded memory, and cancellation/cleanup.
2. Build the independent connection/setup explorer and local browser check.
3. Add explicit file staging to the composer and route palette pickers through
   it; preserve staging across recipient changes and keep text drafts scoped.
4. Recompose the landing around the wide lab, selectable Blender stories,
   connection explorer, useful installation content, and compact help. Keep
   meaningful motion with static reduced-motion behavior and no scroll locking.
5. Update browser regressions for the intentional sender-offer step and add
   dedicated lab, explorer, stories, and staging coverage.
6. Build a stable production preview; run suites sequentially because real
   app clients share discovery. Review screenshots and fix both functional and
   visual findings. Record results, source links, and explicit coverage limits.

The lab, explorer, and staging work have separate file ownership and run in
parallel. Root owns integration, page composition, legacy regression updates,
and final validation. Production protocol framing and coordinator stay intact.
