# Bonjou Web product context

Bonjou Web lets people chat and transfer files from a browser without accounts.
The marketing page and workspace share one React application. The Go CLI is a
separate LAN product; the Go relay supports the browser app's network transport.

Use calm, precise language. Explain approvals, peer verification, encryption,
and their actual limits. Do not imply that a browser can discover LAN CLI peers
just because the clients share cryptographic primitives.

Keep the app fast, responsive, keyboard accessible, and consistent with
`DESIGN.md`. Use real product behavior and repository statistics; avoid invented
metrics, testimonials, and security claims. Keep installation routes easy to
find without crowding the browser workspace.
